代理池入池评估

来源可入池性说明
StagVPN 3 节点技术可行 / 授权存疑接口公开无鉴权 → 可用 OpenVPN 客户端直接拨号转 SOCKS。但这些是 Stag 运营方的生产设施，接入线上池属未授权使用第三方基础设施，需自行评估风险（IP 被封 / 法律边界）。
Wolf SG 节点当前不可用端口全部超时，即便解密成功也无产出。
结论按 VPN-US / VPN-Super / VPN.lat 三单的老规矩：本研究产出（协议文档 / 密钥 / 工具链 / demo）可以完整沉淀；节点 IP 本身不建议直接进生产池，优先作为压力测试与协议验证靶标。
